# 午夜小摊 v0.13 — 手工备菜与售卖闭环

## 新增玩法

- 采购得到的是原料包，不是可直接出售的成品。
- 三款菜品都需要玩家在制作台按 Enter 手工启动制作：
  - 烤饭团：米饭 ×1 + 海苔 ×1，制作约 2.6 秒。
  - 热汤：汤底 ×1 + 蔬菜 ×1，制作约 4.2 秒。
  - 柠檬茶：柠檬 ×1 + 茶底 ×1，制作约 1.8 秒。
- 每个原料包制作出一份对应成品。制作开始时消耗原料，计时完成后成品入库。
- 售卖只能消耗成品库存；原料不能直接上菜。缺成品时，订单提示玩家去制作台备菜。
- 备货与成品共用 15 格总仓储，每款菜品的原料与成品合计最多 8 份。
- 每日结算增加“本晚制作份数”。现金、原料、成品库存和口碑可延续到下一晚。
- 保留顾客移动、排队、需求/预算/耐心、定价、口碑、现金与时间 HUD 和每日结算。

## 操作

- WASD / 方向键：移动
- B：打开原料采购 / 从制作台返回采购
- C：走到左侧小备菜台附近打开制作台 / 从订单切换制作
- 1 / 2 / 3：选择菜品
- 原料采购面板：左右键调整采购数量，Enter 购买原料包
- 制作台：Enter 开始制作，等待进度完成；完成后成品自动入库
- F：备好至少一份成品后开始营业
- E：接待已到达的队首顾客
- 顾客订单：1 / 2 / 3 选成品，左右键调价，Enter 上菜
- B：从顾客订单切换至采购；C：从顾客订单切换至制作台
- Esc：关闭面板；有待服务顾客时可从采购/制作面板返回订单

## 导入

1. 解压到新的文件夹，不要覆盖之前已验证的项目。
2. 在 Godot 4 项目管理器导入 `project.godot`。
3. 按 F5 运行。

## 验收

1. 走到主摊位左侧的小备菜台，按 C 打开制作台；采购仍在主摊位附近按 B 打开。

1. 开局按 B 采购原料包，切到 C 制作台。
2. 分别选择 1/2/3，按 Enter 制作，观察原料减少、制作计时推进、成品增加。
3. 不制作成品就开始营业，应提示先制作；订单只能出售成品。
4. 成品为 0 但有原料时，订单应提示切换制作台。
5. 制作完成数量在每日结算里记录；下一晚原料和成品库存保留。
