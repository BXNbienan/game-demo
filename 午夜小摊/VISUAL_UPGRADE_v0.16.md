# 午夜小摊 v0.16 — 画面清晰度升级

## 本版目标
- 窗口默认改为 1280×720，四倍整数倍率显示。
- 从 `viewport` 渲染模式切换到 `canvas_items`，让 draw_string 字体在目标分辨率下栅格化，而不是先在 320×180 中低分辨率绘制再放大。
- 全局默认纹理过滤设为 Nearest，减少像素纹理模糊。
- 保留 320×180 的逻辑世界坐标、角色逻辑、碰撞与所有玩法代码。
- 增加农场草地、田块、木路、灯光、摊位遮雨棚和柜台的像素细节。

## 导入
1. 解压到新文件夹。
2. Godot 项目管理器 Import `project.godot`。
3. 按 F5 运行。

## 验收建议
- 检查窗口是否以 1280×720 打开，画面是否填满。
- 检查中文 HUD / 菜单文字是否比旧版更清晰。
- 测试农场种植、角色碰撞、顾客移动、备货、火候小游戏、售卖与每日结算。

说明：本版本已静态修改与打包检查；当前环境没有安装 Godot，未能在引擎内实机启动。若 1280×720 不适合你的屏幕，可在 project.godot 中把 window override 改回 960×540；整数倍率仍保持 3 倍。
