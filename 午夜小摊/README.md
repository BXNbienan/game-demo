# 午夜小摊 v0.15 — 白天小屋农场与夜晚夜市

## 新增：昼夜双阶段与种植系统

- 游戏从白天的小屋农场开始；玩家可移动到田地前按 E 操作。
- 空地第一次按 E 开垦，第二次按 E 播种；1/2/3 切换稻种、菜种、柠檬苗。
- 种植中的作物每天需要浇水一次。进入下一天时，只有前一天浇过水的作物才增长一天。
- 稻米成熟需要 3 个有效生长日，蔬菜需要 2 天，柠檬需要 3 天。
- 稻米和蔬菜收获后土地保留，可重新播种；柠檬植株收获后保留，浇水约 2 个生长日后可再次收获。
- 收获的稻米、蔬菜、柠檬会进入共享作物库存，分别作为烤饭团、热汤、柠檬茶的自种原料。
- 夜市采购从“完整原料包”改为采购配套辅料：海苔、汤底、茶底。每道菜制作时都需要 1 份自种作物和 1 份对应辅料。
- 三种菜品仍保留炒锅动画、火候小游戏、品质记账、顾客移动、排队、售卖、金额 HUD 和每日结算。
- 进入每日结算后按 Enter / 空格进入下一天小屋；植物根据前一白天的浇水情况生长，库存、现金与口碑按现有规则保留。

## 初始条件

- 第 1 天在小屋开始，稻米、蔬菜、柠檬各有一块成熟作物，便于体验首夜经营。
- 玩家拥有稻种、菜种、柠檬苗各 2 包 starter seeds。
- 按 T 可在小屋睡到第二天，作物仍只会在前一天浇过水时推进生长；若准备阶段没有可用收成，可按 H 从夜市准备阶段返回小屋。
- 稻种 ¥2、菜种 ¥3、柠檬苗 ¥4；按 B 打开小屋种子箱购买。
- 每种作物收获 2 份作物原料（仓储不足时按剩余空间收获）。
- 柠檬属于可再生植株；稻米与蔬菜收获后需要重新播种。

## 操作

### 小屋白天
- WASD / 方向键：移动
- 1 / 2 / 3：选择稻种、菜种、柠檬苗
- E：与最近地块互动（开垦、播种、浇水或收获，取决于地块状态）
- T：睡到第二天，推进浇水作物的生长
- B：打开种子箱；← / → 调整购买数量；Enter 购买；Esc 关闭
- F：前往夜市

### 夜市
- WASD / 方向键：移动
- B：购买海苔 / 汤底 / 茶底辅料
- C：打开备菜台
- 1 / 2 / 3：选择菜品
- Enter：开始制作
- 制作中按 SPACE：判定火候
- H：未开业且尚无顾客入场时，从夜市准备阶段返回小屋
- F：有成品后开始营业
- E：接待队首顾客
- 订单中 1 / 2 / 3 选菜，左右键调整售价，Enter 上菜
- 结算界面 Enter / 空格：进入下一天

## 食材规则

| 菜品 | 自种原料 | 夜市采购辅料 |
|---|---|---|
| 烤饭团 | 稻米 ×1 | 海苔 ×1 |
| 热汤 | 蔬菜 ×1 | 汤底 ×1 |
| 柠檬茶 | 柠檬 ×1 | 茶底 ×1 |

不能直接出售自种作物或辅料。制作开始时会各消耗一份，计时结束后成品入库。对应作物的种植成本会附着到产物库存，并在制作后随成品进入销货成本核算。

## v0.16 画面清晰度升级

- 默认游戏窗口调整为 1280×720；逻辑世界仍保持 320×180，不修改玩法坐标与碰撞逻辑。
- Stretch 模式改为 `canvas_items`，文字在目标分辨率下绘制，减少低分辨率 viewport 放大造成的文字粗糙。
- 采用 4 倍整数缩放，避免非整数倍率造成像素拉伸不均。
- 全局默认纹理过滤设为 Nearest，保持像素素材边缘干净。
- 为农场草地、田块、夜市地砖、灯笼暖光和摊位木纹增加了局部细节。

若窗口超出屏幕，可在 `project.godot` 中把 `window_width_override` / `window_height_override` 改回 960 / 540；如果要最大化文字清晰度，请保留 `canvas_items` 并确保窗口缩放为整数倍率。
